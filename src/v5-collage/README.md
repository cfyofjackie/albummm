# V5 — 参考排布 01

入口：`#/collage`（旧开发地址 `/?prototype=v5-reference-layout` 仍可用）

上传规则补充：一次可以选择任意张数，系统按选择顺序采用前 10 张合规照片；多余的合规照片跳过并提示数量，比例或格式不合规的照片单独说明。少于 10 张时保留原拼贴并说明缺口。

这是 V5 的第一个可运行案例。它实现参考图的十图排布关系：十个位置、倾斜角度和前后层级；十张图没有主次，全部按相同画面面积等比缩放。算法会先识别横图、竖图和方图的构成：横图偏多时使用横向阅读带，竖图偏多时使用上三 / 中四 / 下三的紧凑簇，方图偏多时使用紧凑方格簇，横竖均衡时保留参考图式的错落排列；随后按槽位的适配比例重新安排照片，而不改变任何照片本身的比例。边框（无 / 拍立得）与装饰（无 / 手帐涂鸦）可独立切换。开启手帐涂鸦后，系统会从猫、狗、花、相机等统一黑色线稿素材中，挑选最多两个放进照片旋转外框之外的大留白；空间不足时会自动少放或不放，且结果对同一组照片保持稳定。

上传规则：一次正好上传 10 张 JPG、PNG 或 WebP，且每张比例需接近 4:3、3:4、1:1、3:2 或 2:3。所有照片按原始比例完整显示，不拉伸、不裁切。

高清查看：点击任一照片会以它在当前拼贴中的实际位置为起点，进入独立的拼贴查看场景。普通页面使用 1600px 预览图；页面空闲时预先生成一张拼贴快照，开合和换图时只移动这张图，减少 Safari 对十张旋转照片的重绘。外层画面尺寸固定，4:3 导出边界在镜头停稳后显现，避免开合时反复重绘大画框。快照未完成时仍可用原预览图进入查看。镜头停稳后，选中照片与遮挡者由独立高清层显示，原图也在停稳后才解码，不占用移动过程。独立高清层绕开 Safari 对缩放画布的低清晰度光栅化。

真正压在选中照片之上的邻居按原拼贴的 z 顺序覆盖，在照片内部为 30% 不透明度，在边缘逐渐恢复原本的不透明度。旋转裁剪按 4:3 画布的实际横纵尺度计算。导出先补回选中照片，再按相同顺序和柔边规则重画遮挡者。再点当前照片、点关闭按钮或按 Esc 返回完整拼贴。导出分三个档位：日常保存（1600 × 1200 JPG）、高清留存（2400 × 1800 JPG）、无损 PNG（2400 × 1800），都只包含当前镜头的 4:3 成品画面。
