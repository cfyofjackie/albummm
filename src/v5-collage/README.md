# V5 — 参考排布 01

入口：`#/collage`（旧开发地址 `/?prototype=v5-reference-layout` 仍可用）

上传规则补充：一次可以选择任意张数，系统按选择顺序采用前 10 张合规照片；多余的合规照片跳过并提示数量，比例或格式不合规的照片单独说明。少于 10 张时保留原拼贴并说明缺口。

这是 V5 的第一个可运行案例。它实现参考图的十图排布关系：十个位置、倾斜角度和前后层级；十张图没有主次，全部按相同画面面积等比缩放。算法会先识别横图、竖图和方图的构成：横图偏多时使用横向阅读带，竖图偏多时使用上三 / 中四 / 下三的紧凑簇，方图偏多时使用紧凑方格簇，横竖均衡时保留参考图式的错落排列；随后按槽位的适配比例重新安排照片，而不改变任何照片本身的比例。边框（无 / 拍立得）与装饰（无 / 手帐涂鸦）可独立切换。开启手帐涂鸦后，系统会从猫、狗、花、相机等统一黑色线稿素材中，挑选最多两个放进照片旋转外框之外的大留白；空间不足时会自动少放或不放，且结果对同一组照片保持稳定。

上传规则：一次正好上传 10 张 JPG、PNG 或 WebP，且每张比例需接近 4:3、3:4、1:1、3:2 或 2:3。所有照片按原始比例完整显示，不拉伸、不裁切。

高清查看：点击任一照片会以它在当前拼贴中的实际位置为起点，进入一张独立的高清拼贴场景。普通页保留轻量预览，查看场景优先读取本地原图，并沿用相同的排布、相纸、背景和装饰数据；因此放大后仍能看到相邻照片与周边元素。进入动画完成后，查看层会完全遮住产品页面，不会露出标题、按钮或原拼贴。为绕开手机浏览器对整板缩放层的低倍率光栅化（所有照片整体发软），镜头到位后当前选中的照片会按最终屏幕尺寸以独立高清层重渲染；点其他照片移动镜头时，高清层跟随切换到新选中的照片。高清层不改变拼贴的遮挡关系：真正压在选中照片之上的邻居会以约 45% 透明度的「幽灵层」覆盖在高清层之上（裁剪到与选中照片相交的范围），既能看清被盖住的内容，也保留「有东西盖在上面」的读感。场景内点击其他可见照片只移动镜头、不重建页面；再点当前选中的照片、点关闭按钮或按 Esc 会平滑返回完整拼贴。导出分三个档位：日常保存（1600 × 1200 JPG，适合分享）、高清留存（2400 × 1800 JPG）、无损 PNG（2400 × 1800，归档用），都把当前镜头的独立 4:3 成品画面渲染成图片，不包含按钮和提示文字。原图仅在悬停/查看时按需解码，并在换图或离开 V5 时释放本地引用。
