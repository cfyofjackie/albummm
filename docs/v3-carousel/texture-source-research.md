# V3 Carousel：现成纹理 / 图案背景素材来源

**目的：** 给下一轮 V3 背景探索找可先浏览的现成素材；本轮不下载、不把素材接入产品，也不生成图片。

**用词说明：** 以下写的是「授权相对宽松」或「CC0 / 公共领域标记」，不等于绝对意义上的“无版权”。最终选择某一张时，仍应回到该素材详情页复核授权、排除人物 / 商标 / 受保护艺术品，并保存来源链接、作者、下载日期和授权页截图。

## 2. 适合 V3 的检索词

先搜索英文，结果更完整。不要只搜 `pattern`，它很容易得到模板感太强的图。

| 要找的感觉 | 优先关键词 | 选图时应该看到 |
| --- | --- | --- |
| **意象海浪 / 水流** | `abstract water ripple`, `indigo water texture`, `translucent wave`, `water caustics`, `undulating lines`, `liquid shadow` | 没有明确海岸线 / 船 / 人，波纹能被裁成局部；最好有大块平静区域。 |
| **清新、轻一点的有机形状** | `organic ink wash`, `soft fluid shape`, `airy abstract`, `pastel organic shape`, `botanical shadow` | 大形状少、边缘柔和；不要糖果色渐变、3D 球或科技流体。 |
| **斑点 / 颗粒** | `organic dots`, `soft speckle texture`, `subtle stipple`, `handmade paper grain`, `ink flecks` | 斑点大小不规则但密度低；应像纸面细节，不应变成密集 confetti。 |
| **纸张 / 织物** | `soft paper grain`, `handmade paper texture`, `rice paper texture`, `linen weave`, `cotton paper` | 纹理对比很低、可平铺、无折痕主体与大水印感；适合放在照片后方。 |
| **更明确的线条图案** | `wavy line pattern`, `contour lines`, `current lines`, `minimal wave svg` | 线条数量少、方向一致、能被改成单色低透明度；不要几何棋盘或赛博网格。 |

## 3. V3 的背景选材规则（设计建议，不是授权事实）

用户想要的是「有花纹、但仍清新和克制」，因此应把素材视作**一层可裁切的环境**，不是完整壁纸。

1. **优先可裁切、无主体、无文字的素材。** 背景只有在被照片盖掉 60–80% 后仍成立，才适合 V3。
2. **一个作品只用一种纹理语言。** 例如全组同一张淡蓝水纹的不同裁切；不要第 1 页海浪、第 2 页斑点、第 3 页花纸。
3. **先用半透明色层把素材压下去。** 浅底可叠 80–92% 暖白，深底可叠 70–85% 深墨；用户照片和白边必须始终是第一视觉。
4. **选“一次局部出现”优先于“每页满铺”。** 例如水纹只在第 2–3 页的底部经过，末页留一小段回声；这比满页海浪更符合 V3 已经确定的连续节奏。
5. **不要让素材跨页切开一张用户照片。** 跨页的只能是背景纹理 / 色块本身，照片排版与智能分页不变。
6. **风格归属建议：** Gallery 用纸纤维 / 低对比水纹；Muse 用半透明波形 / 淡色手工纸；Weekend 用有机点阵 / 轻波线。三者不必各用一张完全不同的“花图”。

## 4. 使用前的最小授权检查

- 把素材作为一个已渲染 carousel 背景的一部分，而不是给用户提供“原图下载”。Unsplash、Pexels、Pixabay 都对**未实质修改的独立转售 / 再分发**有明确限制。
- 一张素材最终入库时，记录：素材详情页 URL、作者 / 来源、下载日期、授权类型、是否含人物 / 商标 / 艺术品、是否需要署名。
- **CC0 优先，CC BY 次之。** CC BY 需要在产品或导出成品中有合适的可见署名 / 许可链接方案；做不到就不选。
- 不要只因素材写“royalty-free”就默认可以任意再分发；也不要把第三方网站的搜索页当成单张素材的授权证明。

## 5. 建议的第一轮挑选方式

不急着找 20 张。先从上面站点各挑一张候选，限定为：

- 一张 **蓝灰水纹 / 波影**；
- 一张 **暖白手工纸纤维**；
- 一张 **低密度有机斑点 / 单色波线 SVG**。

让三张都在同一组 14 张照片、同一份智能分页上各试一次。只要其中一张在移动端连续横滑、又单页导出都成立，再进入 V3 的背景母板；其余先不进仓库。
