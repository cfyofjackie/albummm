# V3 Carousel：背景方向参考与建议

**目的：** 回应「更有对比、但仍克制」的背景方向。这里不提出立刻改动；先把可验证的方向和排除项说清楚。

**先说判断（设计建议，不是事实）：** 现有背景的问题不在于颜色不够多，而在于它们大多是「全页渐变 + 全页纹理 / 网格」：气氛有了，但没有一个明确的**结构性对比**。照片又有白边，于是背景容易显得像一层柔和滤镜，撑不起 Carousel 的连续张力。

下一轮不应加更复杂的纹理或更多颜色。我建议把背景从「纸色变化」升级为一个低频的 **舞台结构**：一张/一组作品只选一个强动作（深色底、硬边色场、边栏、或连续线），其余部分尽量安静。这样既有反差，也不会把照片变成背景的配角。

## 1. 参考中实际可观察到的结构

以下项目均来自设计方自己的项目页。观察是对其公开画面与项目说明的归纳；**不是授权素材，也不建议复制其字体、照片、图形或成品版式。**

| 参考 | 可确认的做法 | 对 V3 有价值的不是 |
| --- | --- | --- |
| [Sight and Sound / Pentagram](https://www.pentagram.com/work/sight-and-sound) | 项目使用黑色的连续底盘；有限辅助色被用来区分 section，并配合显性网格与竖排信息。 | 不是把 V3 做成杂志封面；是「深色为主，颜色只承担分段」的对比方法。 |
| [Serif / Pentagram](https://www.pentagram.com/work/serif) | 项目说明明确写到黑白作为基础，仅在少数时刻使用柔和渐层 / colour wash；色彩承担主题高亮。 | 不是每页都上渐变；是「中性底 + 低频色彩事件」的节制。 |
| [The Meteor / Pentagram](https://www.pentagram.com/work/the-meteor) | 项目说明强调强烈黑白摄影与有限色彩；颜色也用于区分不同栏目。 | 不是把用户照片染成某个品牌色；是让一块有边界的颜色负责视觉反差。 |
| [NAVER Blog / studio fnt](https://studiofnt.com/Naver-Blog) | 设计方把留白当作可扩展的 graphic field；用从 cursor 推导的线表示流向、用 selection 式实心矩形表示强调。 | 不是再铺一层网格；是把留白视为背景本身，并用少量有方向的几何动作激活它。 |
| [Onmaru / studio fnt](https://studiofnt.com/Onmaru) | 项目以黑、白、金属色的克制调色与一个连接线 motif 统一不同媒介。 | 不是模拟科技品牌；是用一条重复但稀疏的规则形成连续性。 |
| [Motiva / Pentagram](https://www.pentagram.com/work/motiva) | 项目采用黑、白、Manila（柔和桃色）与灰阶作为主要调色，目标是让视觉层退后、给艺术内容空间。 | 不是再增加纸张噪声；是有限底色与清晰反差可以同时安静。 |

## 2. 值得为 V3 做成原型的五种背景系统

下面都是**推荐**，不是从参考中直接复制出来的模板；它们都不动照片的分页、尺寸、位置、白边或材质轴。

### A. Inverse Gallery：深墨底 + 白相纸

**画面：** 全页使用几乎黑但不纯黑的墨色（如 `#20201d` / `#23262b`）；照片仍是现有白边。背景只保留非常弱的纤维颗粒和页脚细线，文字改为暖灰白。

**为什么先试它：** 这是最直接的「强对比但克制」。反差来自纸白与墨底的面积关系，不来自图案。混合上传时，各种照片都会被同一张深色舞台托住，尤其适合城市、夜景、建筑、偏电影感的旅行照片。

**限制：**

- 一组作品只用这一种深色，不要每页轮换深蓝、深绿、深酒红；
- 不叠加现有网格，也不加明显阴影；
- Gallery 可新增这个**夜间分支**，但原有浅色 Gallery 必须保留；Muse / Weekend 不借用。

**参考关系：** 取的是 Sight and Sound 的深色连续底盘、Serif 的黑白基底思路，而非其具体视觉元素。

### B. Hard-edge Colour Field：浅纸底 + 一块硬边深色场

**画面：** 75–85% 是暖白 / 冷灰纸；剩余是一块明确边界的深酒红、苔绿、墨蓝或巧克力色。色场可贴页面一侧、底部，或跨两页以同一基线移动；**不要做从左到右的四级渐变。**

**为什么适合当前 V3：** 现有白边照片可以自然压在纸底和色场的交界附近，形成对比与层次，同时保留大面积呼吸。它比全页换色更像 editorial 版面，也比网格更容易形成作品带的连续节奏。

**分配建议：**

- Muse 的优先方向；一组使用一个主色（例：暖白 + 氧化酒红），最多再有一个同色系浅阶；
- 每页最多一块，面积 15–28%；
- 连续 5 页不要都在同一位置：可用「左 / 无 / 右 / 无 / 左」的低频节奏；
- 色块在照片下方，但不需要为了它移动照片。

**参考关系：** 对应 NAVER Blog 用实心矩形做“强调与扩张”的方法，也和 The Meteor 将色彩限定为栏目 / 强调层一致。

### C. Running Edge：连续深色边栏 / 底栏

**画面：** 不是给整页上深色，而是在每页固定 8–14% 宽度的左边栏，或 10–16% 高度的底栏。它跨页保持同一位置，内部只容纳现有页码、`FRAME` 或空白；可以在某一页突然加宽为 24%。

**为什么适合 Carousel：** 用户左右滑时会立即看到一条连续的“轨道”。它有胶卷般的流动暗示，但不会变成仿真胶片；并且比随机的小色点更有识别度。

**风格归属：**

- Muse：窄竖栏搭配现有 type rail；
- Weekend：底栏搭配 archive tag；
- Gallery：可只用 1px 深灰连续线，不用实色栏。

**限制：** 这不是新装饰物。栏内不塞 logo、贴纸或假文案；不让照片跨页裁开；色栏只作为背景层。

**参考关系：** Sight and Sound 的分段色彩和 Onmaru 的连接线，说明稀疏、可重复的规则能在多个画面间形成一致性。

### D. Proof Sheet / Contact Field：淡纸底 + 极大但极淡的框线

**画面：** 不再使用细密小网格，改为很稀疏的大框（约 2×3 或 3×4 个隐约区域），并且只有相邻两页共享一段对齐线；线的可见度比当前 Weekend 网格更低，但尺寸大得多。

**为什么它可能比现有网格更好：** 小格纹有明显的“背景贴图”味；大框会像摄影接触印样或版面基线，和散落相纸建立尺度关系，但不抢照片。强度来自**尺度对比**而非颜色。

**风格归属：** 最适合 Gallery 的浅色版本、或 Weekend 的低密度版本；不与深墨底同时使用。

**限制：** 不能变成每页完整九宫格，也不要出现假坐标 / 伪数据。线不穿过照片内容时才显眼；即使被照片盖住也应当是背景，不要为了露线重排照片。

**参考关系：** Motiva 的“可见又安静”的网格平衡、NAVER Blog 的留白场，支持这种极少量结构线，而非更高频的纹理。

### E. Quiet Wash：中性底 + 一次局部色雾

**画面：** 不是全页线性渐变，而是一组最多出现 1–2 页的、边缘很软的局部色雾，例如雾蓝从右下角淡入 20% 面积，或灰粉在左上角停住。其余页面纯纸。

**为什么保留这个较弱的选项：** 对人像 / 花 / 咖啡这类 Muse 内容，局部色雾能保留柔软感；它应该是系列中的一个“停顿”，而不应成为所有页的默认背景。

**限制：** 色雾没有文字、没有额外形状、没有第二种颜色；一组不超过两页。若照片本身已高饱和，则不出现。

**参考关系：** Serif 官方项目明确采用黑白基底，并只在少数时刻使用柔和的色彩 wash；V3 只借用这种频率控制。

## 3. 我的推荐顺序

如果只做一轮背景母板，我会做 **A + B + C**，而不是把五种都加进产品：

| 原型 | 预计观感 | 适合验证的问题 |
| --- | --- | --- |
| **A / Inverse Gallery** | 最有冲击力、最不依赖照片颜色 | 深底 + 白边能否成为 V3 新的高对比分支？ |
| **B / Muse Hard-edge Field** | 最像时尚 editorial，仍保留大留白 | 色块能不能比全页渐变更有版面感？ |
| **C / Weekend Running Edge** | 最明显地加强横向连续感 | 不依赖跨页裁图，能否让 Carousel 看起来是一件作品？ |

它们对应三种不同的背景逻辑，因此试完能得到明确结论；D / E 可以等前三种看完后再补。

## 4. 明确不建议的方向

- **继续加颜色阶数或把现有渐变调得更深。** 它只会让“背景在换色”的问题更强，未必让版面更有结构。
- **给所有风格都加同一张网格 / 噪声。** 风格会重新混在一起，且移动端易显脏。
- **深色底 + 密网格 + 大颗粒 + 阴影同时存在。** 对比会从“编辑感”退化为“效果堆叠”。
- **让色块承载假的地点、日期、情绪句子。** 目前没有可靠的用户输入；背景应组织照片，不代替照片讲故事。
- **把用户照片做统一 duotone / 滤镜。** 这会改变上传照片的色彩意图；背景实验不应碰照片内容。

## 5. 原型验收口径

下一步应做一个独立的 background-masters 原型，保持现有 `carousel-smart` 不变。每个方向只准备一套固定背景规则，使用相同的 14 张示例和同一份智能分页结果对照。

验收时重点看：

1. 5–6 页横向连看时，背景是否有连续结构，而不是逐页换皮；
2. 单页截出来发社媒时，是否仍然像完整的设计；
3. 深 / 浅、横 / 竖、高饱和 / 低饱和照片是否都仍然是第一视觉；
4. 预览和 4:5、3:4、4:3 导出是否一致；
5. 只改变背景，不改变分页、卡片尺寸、白边、材质与第二档装饰。

**建议你先看 A / B / C 的同组照片对比，再决定哪一条进入 V3 主线。**
