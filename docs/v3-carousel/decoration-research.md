# V3 Carousel：适合加入的装饰研究

**目的：** 为 V3 的下一轮「排版层装饰」选方向；不是新增另一套拼贴模板，也不是寻找可直接拷贝的素材。

**结论先行：** V3 应继续用**低频、系统化、留在照片内容区外**的装饰建立连续感。最适合下一轮落地的是：

1. Muse 的竖向 type rail + 一块低饱和色带面板；
2. Weekend 的数据化日期戳 / 色块标签；
3. 全风格共用但极轻的跨页延续线。

Gallery 保持目前的页脚、micro-label 与纸面，不再加新物件。现有的拍立得边框、毛边、和纸胶带已经属于材质轴，**不应再把它们当成可随处添加的装饰**。

---

## 1. 筛选标准

本轮只考虑符合下面全部条件的图形语言：

- 像出版物或品牌系统，而不是贴纸库；
- 每页最多一个新强调，整组重复的是规则而不是图案；
- 不盖住照片内容，也不要求主图缩小来腾位置；
- 能用 `cqw`、CSS 变量和 `layout/` 数据在预览与 PNG 导出中同比例渲染；
- 不改变智能分页、2–4 张页、最小尺寸、内容区零碰撞等既有规则；
- 不依赖用户额外填写文案。只有真实 EXIF 日期 / 已有照片序号可作为数据来源；缺数据时隐藏，而不是编造。

这与现有参考图清点的结论一致：好的 Carousel 并不是「多贴几个元素」，而是用小号文字、细线、页码、留白和有限色块把照片组织成一件连续作品。

---

## 2. 值得采用的装饰模式

| 优先级 | 模式 | 最适合风格 | 具体做法 | 严格边界 |
| --- | --- | --- | --- | --- |
| A | **竖向 type rail** | Muse | 在页面最外侧的留白边缘放一条 90° 旋转的极小衬线文字；可用风格词与 `01—05`，而不是长标题。它与图片不相交，作为贯穿多页的阅读方向。 | 每组 2–3 页；最多 14 个英文字符；不压图；没有作品标题输入前，不生成假诗句、地点或情绪文案。 |
| A | **低饱和色带 / 色块面板** | Muse | 一块窄色带贴在页边或在照片间的空白处，搭配 type rail 或小号序号；色带位置由页级装饰数据决定，不跟随照片随机漂移。 | 每页最多 1 块；只能是纸面色系的低对比色；必须避开卡片安全盒，不能用来遮住图片。 |
| A | **日期戳 / archive tag** | Weekend | 用固定位置的小号无衬线日期戳（如 `18 SEP 2026`）+ 短横线 / 实心小色块，形成更轻快的记录感。 | 只在照片 EXIF 日期存在时显示；无 EXIF 时只保留 `FRAME 07` / 页码，不能捏造日期或城市；每页一处以内。 |
| B | **跨页延续线** | 三种风格 | 在同一基线放一根极细线，和既有页脚并行或仅在画面中上部的边缘出现；偶尔用一小段色块标记当前页。它提示「连续画布」，不是胶片齿孔。 | 占页面高度不超过 1%；不穿过照片内容；不强行把图片跨页面裁开；Gallery 只用灰线，Muse/Weekend 才允许小色段。 |
| B | **contact-strip 观察窗** | Weekend（实验） | 从**本页已有照片**取 1–2 个很小的局部，排成窄条，作为“细节回声”；适合照片多、空白足够的 3–4 图页。 | 不是再加图片，也不能让主图变小；仅在版面有足够留白时生成；每组最多 1 页；四图页默认关闭，避免重新滑向 scrapbook。 |
| B | **描图纸式透明面片** | Muse（实验） | 一块有轻微边缘高光的半透明纸面，承载已有的页码或 type rail，制造 editorial 的层次，而非手账纸片。 | 每组最多 1 页；仅 8–15% 的页面面积；不出现斜贴、阴影堆叠或黄旧纸感；若落在卡片附近，其矩形须进入安全盒。 |

### 为什么这些方向适合 V3

- **竖排文字、色带与极小元数据**可把同一组照片组织为连贯的编辑设计，而不把每页变成一张模板。Pentagram 为 Porsche 制作的 Ramadan 社媒项目用一条连贯的“线”连接不同画面；其价值在于用一个重复规则建立连续性，而非堆多种装饰。[Porsche / Pentagram](https://www.pentagram.com/work/porsche)
- **色块应是有组织的系统，而非背景噪声。** Pentagram 的 Coqual 项目以模块化色块组织信息，说明色块可以成为内容层级工具；V3 只借鉴这一“有限模块”方法，并遵守自身纸面低彩度限制。[Coqual / Pentagram](https://www.pentagram.com/work/coqual)
- **留白本身是可用空间。** Studio fnt 为 NAVER Blog 设计的系统把“光标之后尚未写入的空间”当作可扩展的图形场，并用线与实块建立可扩展规则；这支持 V3 把 rail、色块留在边缘和空白，而不是叠在照片上。[NAVER Blog / studio fnt](https://studiofnt.com/Naver-Blog)
- **编辑系统需要稳定网格和少量可重复的细节。** MIT Technology Review 的设计以明确网格和一个固定角度组织图像与文字，适合借鉴为 V3 的页边规则，而不是模拟其视觉样式。[MIT Technology Review / Pentagram](https://www.pentagram.com/work/mit-technology-review)
- **连续感可以由跨帧提示带来。** Shell Open Air 的原始 Carousel 项目以跨 frame 的画面延续制造“超出单页”的感受；V3 应只取其连续提示，不能切用户主体或把跨页拼接变成要求。[Shell Open Air / 原作者 Behance](https://www.behance.net/gallery/92481519/SHELL-OPEN-AIR)

这些链接是灵感与原则的来源，**不是素材授权**。不得下载、截取或复用来源中的纹理、字体、照片、矢量或版式成品。

## 3. 明确不做的方向

| 不做 | 原因 |
| --- | --- |
| 每页一个贴纸、手绘箭头、爱心、emoji、便利贴 | 破坏 V3 的摄影书 / editorial 定位，且会把随机排版误读为手账模板。 |
| 仿真邮票、真实航空标签、旅行票根、品牌 logo | 会制造不真实的叙事数据和版权 / 商标风险，也不适用于非旅行照片。 |
| 大段假文案、鸡汤、手写 quote | 目前没有标题 / caption 输入；生成的文字会比照片更抢眼且很快过时。 |
| 每页都用胶带、毛边、阴影或透明纸 | 现有材质轴已经足够；材质多了会让 2–4 张的受控随机排版变脏。 |
| 胶卷齿孔、胶片编号、35mm 边框 | 胶卷在 V3 只是浏览隐喻，不是导出图片的强制视觉模板。 |
| 跨页切开同一张用户照片 | 连续性不能以主体安全为代价；只允许线、色带、背景或边缘标记延续。 |

## 4. 建议的落地顺序

### 第一小步：第二档「风格专属排版装饰」

这是 handover 文档中的 D1，风险最低：

1. **Muse：** type rail + 单个色带面板；
2. **Weekend：** EXIF 日期戳（无数据退回已有序号）+ 小色块；
3. **Gallery：** 不加新物件，只让现有页脚 / micro-label 保持最克制；
4. 三种风格共享相同的分页和照片几何；差异只能在纸面与装饰参数。

实现时新增一个类似 `pageDecor.js` 的纯函数输出（例如 `styleDecorFor`），让页面装饰有确定 seed、位置、尺寸与可测试的安全盒，而不要把随机参数散落在 JSX / CSS。

### 第二小步：跨页延续线

先作为页级背景 / 排版层，不接触照片。如果线的位置可能与卡片相交，就要么换位置，要么将其矩形并入安全盒。不要把它做成更显眼的“假胶卷”。

### 暂缓：观察窗与描图纸面片

它们比 type rail 和日期戳更容易破坏密度，应该先做单独的 `carousel-<experiment>` 原型；只有在 2、3、4 图页和三种导出规格都稳定后，才考虑进入主线。

## 5. 实现 / 验收清单

- 所有新视觉数值先进入 `src/v3-carousel/layout/`，再以 CSS 变量渲染；预览与导出必须同一套数据。
- 用 `cqw` 或页面百分比，不用预览像素值。
- 任何可能靠近照片的矩形（色块、透明面片、标签）都必须参与安全盒 / 碰撞检查；纯边缘背景线也要在 DOM 层级中确认不遮图。
- 不修改 `carouselSmartPagination.js` 的分页规则、`PAGE_FORMATS` 的重构图逻辑、尺寸边界或现有材质轴。
- 至少检查 Gallery / Muse / Weekend 各一组，和 4:5、3:4、4:3 导出的 PNG；页面不会因新装饰变得更少图、更小图或被遮图。
- 只改 `src/v3-carousel/**` 与 `docs/v3-carousel/**`；单个设计决定单独提交，信息以 `V3:` 开头。
