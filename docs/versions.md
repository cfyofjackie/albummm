# Albummm 版本地图

这个仓库保留三条可并行探索的产品线；它们共享图片读取能力，但不共享排版规则或视觉实现。

| 版本 | 方向 | 代码入口 |
| --- | --- | --- |
| V1 Book | 可翻阅、可收藏的电子相册书 | `src/v1-book/` |
| V2 Collage | 单页 / 多页的照片拼贴作品 | `src/v2-collage/` |
| V3 Carousel | 连续浏览、可发布的照片作品带 | `src/v3-carousel/` |

`src/shared/` 只放跨版本复用的图片读取和演示照片。版本自身的排版、页面和样式必须留在对应目录，以免一个方向的实验影响另一个方向。

根目录的 `src/App.jsx` 只是版本入口：默认进入 V1；带 `?prototype=` 的链接进入 V2 或 V3 的原型页面。旧链接保持不变。
